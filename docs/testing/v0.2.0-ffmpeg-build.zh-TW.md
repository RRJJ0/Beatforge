# Beatforge 0.2.0 FFmpeg 建置證據

[English](v0.2.0-ffmpeg-build.md)

2026-11-05 從本機現有的 Beatforge Windows 受管理 runtime 取得。這是首次設定下載的 `imageio-ffmpeg` 元件證據，不表示 Beatforge 安裝包含有 FFmpeg。

- Python 套件：`imageio-ffmpeg 0.6.0`
- 執行檔：`ffmpeg version 7.1-essentials_build-www.gyan.dev`
- 執行檔 SHA-256：`2ce797a0f88d7f067180338fb227f7b1928ea727bd9a4d7a1d022f7c52af71a3`
- `ffmpeg -L` 指出 GNU General Public License。
- `ffmpeg -version` 回報的設定：

```text
--enable-gpl --enable-version3 --enable-static --disable-w32threads --disable-autodetect --enable-fontconfig --enable-iconv --enable-gnutls --enable-libxml2 --enable-gmp --enable-bzlib --enable-lzma --enable-zlib --enable-libsrt --enable-libssh --enable-libzmq --enable-avisynth --enable-sdl2 --enable-libwebp --enable-libx264 --enable-libx265 --enable-libxvid --enable-libaom --enable-libopenjpeg --enable-libvpx --enable-mediafoundation --enable-libass --enable-libfreetype --enable-libfribidi --enable-libharfbuzz --enable-libvidstab --enable-libvmaf --enable-libzimg --enable-amf --enable-cuda-llvm --enable-cuvid --enable-dxva2 --enable-d3d11va --enable-d3d12va --enable-ffnvcodec --enable-libvpl --enable-nvdec --enable-nvenc --enable-vaapi --enable-libgme --enable-libopenmpt --enable-libopencore-amrwb --enable-libmp3lame --enable-libtheora --enable-libvo-amrwbenc --enable-libgsm --enable-libopencore-amrnb --enable-libopus --enable-libspeex --enable-libvorbis --enable-librubberband
```

[FFmpeg 官方授權說明](https://ffmpeg.org/legal.html)指出，啟用 GPL 元件會改變 FFmpeg 適用的授權。Beatforge 的 `third_party/component-policy.json` 將 imageio-ffmpeg／FFmpeg 列為首次設定下載，不納入 release asset。此建置與散布路徑仍須發布前人工複核。

# UI 設計工作區

[English](README.md) · [開發者文件](../development/README.zh-TW.md)

第一版桌面線框圖的主要來源是 `osu-ai-desktop-wireframes.drawio`，共 14 頁，
涵蓋資訊架構、首次設定、生成、任務狀態、結果、歷史、模型、設定、對話框、
通知與元件參考。

## 視覺方向

- 桌面畫布：1440 × 900
- 導覽：固定左側欄
- 預設外觀：深色
- 主要動作色：參考 osu! 的粉色 `#FF66AA`
- 表面：克制的海軍藍／石板灰層次、細微邊框與高度
- 基本間距格：8 px
- UI 實作目標：Vue 3 + Naive UI

### 產品風格原則

- 固定應用程式標頭與工作區導覽，使工具維持完整桌面產品的感受。
- 粉色保留給已選導覽標記、主要 CTA、進度與聚焦控制。
- 一般卡片保持中性，以間距、字體、邊框對比與高度建立層次。
- 系統健康與生成摘要等技術群組使用 11–12 px 大寫區段標籤。
- 進階或診斷資訊置於次要面板，不與主要流程混在一起。
- 執行前顯示確認摘要，生成後顯示結構化品質報告。
- 狀態使用精簡 badge 與明確階段文字，不依賴裝飾插圖。

## 審查清單

- 使用者從首次啟動到生成 `.osz` 不需使用終端機。
- 缺少 runtime／模型、不支援 GPU、顯存不足、取消、失敗與成功都有可見狀態。
- 進階模型參數不淹沒預設生成表單。
- 長時間操作能看到目前狀態，並有安全離開或復原方式。
- 破壞性操作須區分刪除資料庫紀錄與刪除生成檔案。
- 本機檔案選擇由 Tauri 實作，不使用瀏覽器 upload 控制。

# 分享 AI 輔助譜面

[English](sharing.md) · [首頁](../../README.zh-TW.md)

Beatforge **不會**替你上傳譜面。如果要分享，請先查閱當時的
[osu! 上傳說明](https://osu.ppy.sh/wiki/en/Beatmapping/Beatmap_submission)、
[排名 AI 政策](https://osu.ppy.sh/wiki/en/Ranking_criteria#ai-policy) 和
[譜面上傳規則](https://osu.ppy.sh/wiki/en/Rules#beatmap-submission-rules)。
規則可能改變；本說明最後核對於 2026-10-16。

- Mapperatorinator 生成的草稿，建議先以 **Work In Progress（WIP）** 分享、徵求
  意見，不要當成準備排名的 Pending 譜面。WIP 是本專案建議，並非聲稱 osu!
  強制所有 AI 譜面都使用 WIP 類別。
- 現行排名 AI 政策要求 hit objects、hitsounds 與 timing 由人類直接建立，
  不得使用生成式工具。揭露或事後修改，不會自動讓原本生成的內容符合排名資格。
- 在譜面網站 description 說明 Mapperatorinator 實際生成的部分；`.osu`
  內的搜尋 Tags 不能代替公開揭露。
- 上傳前，確認每個難度的 **Creator** 與你的 osu! 帳號完全一致，包括大小寫；
  並在 osu! 編輯器檢查歌曲資訊、timing、物件與媒體。
- 確認你有權分享歌曲、圖片、影片、hitsounds 與其他素材。通過 Beatforge
  validation 不代表取得授權，也不代表 osu! 官方接受。

英文揭露範例；第二行應依實際生成範圍修改：

```text
This beatmap was generated using Mapperatorinator through Beatforge.
AI was used to generate timing, hit objects, and hitsounds.
Shared as Work In Progress for testing and feedback; not intended for ranking.
Mapperatorinator: https://github.com/OliBomby/Mapperatorinator
```

Beatforge 與 osu! 官方沒有從屬或背書關係。

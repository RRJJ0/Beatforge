# Sharing AI-assisted beatmaps

[繁體中文](sharing.zh-TW.md) · [Home](../../README.md)

Beatforge does **not** upload beatmaps. If you decide to share one, check the
current [osu! submission guide](https://osu.ppy.sh/wiki/en/Beatmapping/Beatmap_submission),
[ranking AI policy](https://osu.ppy.sh/wiki/en/Ranking_criteria#ai-policy), and
[submission rules](https://osu.ppy.sh/wiki/en/Rules#beatmap-submission-rules)
first. Rules can change. This guidance was last reviewed on 2026-10-16.

- A Mapperatorinator-generated draft is best shared as **Work In Progress
  (WIP)** for feedback, not as a ranking-ready Pending map. WIP is our
  recommendation, not a claim that osu! mandates WIP for every AI map.
- The current ranking AI policy requires hit objects, hitsounds, and timing to
  be made through direct human input, without generative tools. Disclosure or
  later edits do not automatically make generated mapping rankable.
- Explain in the beatmap website description what Mapperatorinator generated.
  Search tags inside `.osu` are not a substitute for a clear public disclosure.
- Before uploading, make sure each difficulty's **Creator** exactly matches
  your osu! username, including capitalization. Also inspect song metadata,
  timing, objects, and media in the osu! editor.
- Make sure you have permission to share the music, image, video, hitsounds,
  and any other included content. Passing Beatforge validation is not a license
  check or an osu! approval.

Example description; edit the second line to match what was actually generated:

```text
This beatmap was generated using Mapperatorinator through Beatforge.
AI was used to generate timing, hit objects, and hitsounds.
Shared as Work In Progress for testing and feedback; not intended for ranking.
Mapperatorinator: https://github.com/OliBomby/Mapperatorinator
```

# Beatforge 0.2.0 release notes

[繁體中文](v0.2.0-release-notes.zh-TW.md) · [User guide](../user/guide.md) · [Known limits](v0.2.0-known-issues.md)

These notes describe the 0.2.0 features and acceptance evidence. The exact source commit, installer hashes, and publication date are recorded in `build-provenance.json`, `SHA256SUMS.txt`, and the GitHub Release.

The candidate is Windows Authenticode unsigned. Windows does not show a verified Publisher for this build and may display its normal security warning. Tauri updater signature verification remains required.

## New in 0.2.0

- Shared Creator, Unicode title and artist, song Source, and public Tags can be entered before generation. Public Tags retain the `Beatforge AI mapperatorinator` disclosure; seed, prompts, model paths, and local paths stay out of exported `.osu` metadata.
- Each difficulty can set HP, OD, base slider multiplier, and slider tick rate independently, alongside the existing name, target rating, AR, CS, seed, descriptors, and hitsound controls. Blank fields remain distinct from explicit values. With no reference beatmap, the pinned V32 defaults for HP/OD/slider multiplier/slider tick rate are `5`/`8`/`1.4`/`1`.
- Stored requests support retry without adopting later UI defaults. Worker protocol v2 and provenance schema v2 record requested and applied values per difficulty. The worker checks each generated `.osu` against effective metadata and numeric settings before reporting completion.
- With negative descriptors, the worker now sets the model guidance scale to `1.5` so Mapperatorinator uses the negative prompt; without them, the original `1.0` remains. Job provenance records the effective scale.

## Validation so far

On 2026-11-03, one- and four-difficulty sets generated with pinned V32 on an RTX 4070 matched their stored requests for metadata, HP, CS, AR, OD, blank-field defaults, and shared audio/background/video references. Another no-reference single-difficulty job used slider multiplier `1.6` and tick rate `1.5`; all 439 calculated slider durations were positive and finite, and the user reported normal play in osu!. Same-song reference inheritance for four omitted fields matched the request, provenance, and `.osu` in `BF-1793716316106-4`, and the user reported normal play in osu!. The user also accepted preview and import. The full GPU-free release gate passed, including frontend, Rust, mock-worker, and Python tests.

The negative-descriptor correction was also exercised on an RTX 4070 with pinned V32 and a 20-second audio excerpt, using positive `skillset/jumps` and negative `skillset/streams`. Generation produced an `.osz`, and provenance recorded effective `cfg_scale=1.5`. This confirms the generation path runs; it does not guarantee a particular style or play quality.

## Before release

The [known limits](v0.2.0-known-issues.md) track remaining checks, including other songs and slider value combinations and the production update endpoint. On 2026-11-05, the user reported that the isolated HTTPS `0.1.0 → 0.2.0` normal update, interrupted download, and offline recovery/retry passed, satisfying this version's cross-version update check. The test ran in an everyday Windows account, did not cover clean-environment installation, and has no independently collected GUI evidence. Generated beatmaps still need human mapping and timing review. Published 0.1.0 notes remain in [release-notes.md](release-notes.md).

# Beatforge 0.2.0 known limits

[繁體中文](v0.2.0-known-issues.zh-TW.md) · [Release notes](v0.2.0-release-notes.md)

These limits apply to Beatforge 0.2.0; refer to the GitHub Release for publication details.

- A validated and importable beatmap can still need manual timing, slider, hit-object, and playability review. The accepted four-difficulty hardware run recorded one fallback for a non-positive generated slider length and 24 out-of-bounds object warnings; the single-difficulty run recorded one out-of-bounds warning. These are reported, not silently treated as quality approval.
- Job `BF-1793710433575-1` has a roughly 20-second interval without new objects in its 6s difficulty at about 1:14.287–1:34.349, with multiple objects at the same start time and slider-generation warnings at the interval boundary. The gap is present in both the raw and validated maps; the user reports that it persists after regenerating with a different seed. Deeper investigation is deferred until supported model switching allows a comparison on the same song and difficulty. Passing validation does not establish reasonable object coverage throughout the song.
- One non-default slider pair (`1.6` multiplier / `1.5` tick rate) was generated on hardware: all 439 calculated slider durations were positive and finite, and the user reported normal play in osu!. Same-song reference inheritance for four omitted fields also matches the request, provenance, and `.osu`, and the user reported normal play in osu!. These cases do not establish slider quality for other songs or value combinations.
- The user reports that the isolated HTTPS `0.1.0 → 0.2.0` update, interrupted download, and offline recovery/retry passed; this is accepted as the cross-version update check for 0.2.0. The test ran in an everyday Windows account and did not cover clean-environment installation. The production GitHub updater endpoint remains to be checked. Automated update-state recovery and future-schema rejection passed; older app versions are not guaranteed to read newer job data.
- 0.2.0 still uses pinned Mapperatorinator V32. For first-run downloads, GPU support, and WebView2 requirements, see the [system requirements](../user/requirements.md) and [published 0.1.0 limits](known-issues.md). The current candidate installer has no Windows Authenticode signature; installation on a clean Windows environment was not tested.

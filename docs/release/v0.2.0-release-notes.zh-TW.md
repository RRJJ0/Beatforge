# Beatforge 0.2.0 版本說明

[English](v0.2.0-release-notes.md) · [使用指南](../user/guide.zh-TW.md) · [已知限制](v0.2.0-known-issues.zh-TW.md)

本文件記錄 0.2.0 的功能與驗收證據。確切來源提交、安裝檔雜湊及發布日期以 `build-provenance.json`、`SHA256SUMS.txt` 與 GitHub Release 為準。

候選版未使用 Windows Authenticode 簽章，因此 Windows 不會顯示已驗證的發行者，也可能出現一般安全提醒；Tauri 更新簽章驗證仍為必要條件。

## 0.2.0 新增內容

- 生成前可填寫歌曲共用的譜師、原文標題與歌手、來源及公開標籤。公開標籤保留 `Beatforge AI mapperatorinator` 揭露；seed、提示詞、模型路徑及本機路徑不會寫入匯出的 `.osu` metadata。
- 每個難度可獨立設定 HP、OD、基本滑條速度和滑條點倍率，並保留既有名稱、目標星數、AR、CS、seed、描述詞及 hitsound 控制。空值與明確輸入分開處理；沒有參考譜面時，固定 V32 的 HP／OD／滑條速度／滑條點倍率預設值為 `5`／`8`／`1.4`／`1`。
- 已儲存的任務可依原要求重試，不會套用之後變更的 UI 預設。worker 協定 v2 與 provenance schema v2 逐難度記錄要求值與套用值；worker 在回報完成前逐張核對 `.osu` 的 metadata 與數值。
- 填入負面描述詞時，worker 會將模型引導係數設為 `1.5`，讓 Mapperatorinator 實際使用負面引導；未填時維持原本的 `1.0`。任務 provenance 記錄實際係數。

## 目前驗證結果

2026-11-03 使用固定 V32／RTX 4070 生成的單難度與四難度成果，其 metadata、HP、CS、AR、OD、空值預設及共用音訊／背景／影片引用，均與儲存的要求一致。另一筆無參考單難度任務以滑條速度 `1.6`、滑條點倍率 `1.5` 生成，439 條滑條時長皆為正且有限；使用者回報在 osu! 試玩正常。同歌曲參考譜面四欄空值繼承已在 `BF-1793716316106-4` 的 request、provenance 與 `.osu` 核對，使用者亦回報該筆在 osu! 試玩正常。使用者另已驗收預覽與匯入；完整 GPU-free release gate 通過，包含前端、Rust、模擬 worker 與 Python 測試。

負面描述詞修正另以 20 秒音訊片段、正面 `skillset/jumps` 與負面 `skillset/streams` 在 RTX 4070／固定 V32 實機生成 `.osz`；provenance 記錄有效 `cfg_scale=1.5`。此驗證確認生成路徑可執行，不代表特定風格或遊玩品質保證。

## 發布前待辦

[已知限制](v0.2.0-known-issues.zh-TW.md)記錄其他歌曲與滑條值組合，以及仍待完成的正式更新端點檢查。2026-11-05 使用者回報隔離 HTTPS 的 `0.1.0 → 0.2.0` 正常更新、下載中斷與離線復原／重試通過，作為本版跨版本更新驗收；測試在日常 Windows 帳號進行，未涵蓋乾淨環境安裝，尚無獨立 GUI 證據。生成譜面仍須人工檢查製譜與 timing。已發布的 0.1.0 說明保留於[release-notes.zh-TW.md](release-notes.zh-TW.md)。

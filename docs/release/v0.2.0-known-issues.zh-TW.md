# Beatforge 0.2.0 已知限制（草稿）

[English](v0.2.0-known-issues.md) · [版本說明草稿](v0.2.0-release-notes.zh-TW.md)

狀態：開發草稿；發布 0.2.0 前須再核對本清單。

- 譜面通過驗證並可匯入後，仍可能需要人工檢查 timing、滑條、物件與遊玩性。已驗收的四難度實機任務記錄 1 次非正值滑條長度回退及 24 個物件越界警告；單難度任務則有 1 個物件越界警告。這些問題會顯示，並不代表品質審核通過。
- 任務 `BF-1793710433575-1` 的 6s 譜面在約 1:14.287–1:34.349 出現約 20 秒沒有新物件的區段，且在區段起點有多個同時點物件與滑條生成警告。原始與驗證後譜面均有此缺口；使用者回報更換 seed 重生後仍有相同問題。暫緩深入處理，待支援切換已驗收模型後，以同歌曲、同難度比較不同模型的輸出；目前驗證通過不代表每段都有合理的物件配置。
- 非預設滑條速度 `1.6`／滑條點倍率 `1.5` 已完成一筆實機生成，439 條滑條時長皆為正且有限，使用者回報在 osu! 試玩正常；其他數值組合的品質不能由此推論。同歌曲參考譜面四欄空值繼承也已核對 request、provenance 與 `.osu`，使用者回報該筆在 osu! 試玩正常；此結果仍不能推論其他歌曲或數值組合的滑條品質。
- `0.1.0 → 0.2.0` 真實更新與更新中斷復原，要等 0.2.0 候選版存在才能驗收。自動化的更新狀態復原與未來 schema 拒絕已通過；舊版程式不保證能讀取新版任務資料。
- 固定 Mapperatorinator V32、首次下載、GPU 支援、WebView2 安裝需求與 Windows Authenticode 狀態，在 0.2.0 候選版建置並驗證前，仍以[已發布的 0.1.0 限制](known-issues.zh-TW.md)為準。
